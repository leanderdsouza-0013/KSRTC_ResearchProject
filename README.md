# Crowd Estimation and Time Slot Recommendation for Mangalore KSRTC Bus Services

## Project Overview

The **Crowd Estimation and Time Slot Recommendation for Mangalore KSRTC Bus Services** project focuses on analyzing bus service and passenger crowd patterns to support better travel planning and operational decision-making.

The project uses data analysis and visualization techniques to examine crowd patterns across bus routes and identify potentially suitable time slots for travel. Interactive dashboards present the findings in an accessible format, helping users explore transport patterns and understand variations in estimated crowd levels.

This project was developed as an academic Data Science project, combining data analysis, visualization, and web-based analytics.

## Objectives

- Analyze bus service and estimated passenger crowd patterns.
- Explore variations in crowd levels across different routes and time slots.
- Identify time slots that may be more suitable for travel based on the available data.
- Develop interactive dashboards for exploring transport-related insights.
- Present analytical findings through a Web Analytics Control Center.
- Support data-informed travel planning and public transport analysis.

## Dataset

The project dataset contains **542 records and 19 attributes** related to bus service and crowd analysis.

The dataset supports the exploration of route-based patterns and time-slot variations.

### Dataset characteristics

- **Records:** 542
- **Attributes:** 19
- **Domain:** Public transportation and passenger crowd analysis
- **Geographical focus:** Mangalore
- **Analysis:** Route-based crowd estimation and time-slot analysis

> Note: The analysis is based on the available dataset. It does not use live passenger counts, onboard sensors, or real-time tracking.

## Tools and Technologies

- **Tableau:** Interactive dashboards and data visualization
- **Web Analytics Control Center:** Web-based presentation and exploration of analytical results
- **Data Analysis:** Dataset exploration, pattern identification, and interpretation
- **Data Visualization:** Graphical representation of route and time-slot patterns

## Methodology

The project follows a structured analytical workflow:

1. **Data Collection:** Obtain the dataset containing bus service and crowd-related attributes.
2. **Data Understanding:** Examine the dataset structure, records, attributes, and relevant variables.
3. **Data Preparation:** Organize the available data and prepare it for analysis.
4. **Exploratory Analysis:** Investigate route-based patterns and variations in estimated crowd levels.
5. **Crowd Estimation:** Examine crowd-related indicators available in the dataset.
6. **Time Slot Analysis:** Compare available time slots to identify potentially suitable travel periods.
7. **Dashboard Development:** Create interactive Tableau visualizations to explore the analytical results.
8. **Web Presentation:** Present the project findings through the Web Analytics Control Center.

## Project Outcomes

The project demonstrates how data analysis and visualization can be applied to public transportation problems.

The dashboards provide a structured way to explore crowd-related patterns, compare routes and time slots, and interpret the available data for travel planning.

The analysis can help identify potentially less crowded travel periods within the scope of the dataset. However, actual passenger density may differ from the estimates because the project does not rely on live passenger monitoring.

## Limitations

-  The analysis depends on the completeness and quality of the available dataset.
-  Crowd estimates should not be interpreted as verified real-time passenger counts.
-  The project does not incorporate live bus tracking or sensor-based passenger monitoring.
-  Recommended time slots are analytical suggestions, not guarantees of available seating or lower crowd levels.
-  Findings are limited to the routes, attributes, and periods represented in the dataset.
